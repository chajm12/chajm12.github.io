> 이번에는 같은 환경에서 LLM 에이전트를 만든 두 논문, ReAct와 Reflexion을 읽고 정리했습니다.

## 1. 세 논문의 흐름

| 논문 | 한 일 | ALFWorld unseen 134게임 |
| --- | --- | --- |
| ALFWorld (ICLR 2021) | 시험장을 만들었다. 3D 집안일 과제를 텍스트 게임으로도 제공 | BUTLER 37% (모방학습) |
| ReAct (ICLR 2023) | 생각을 쓰게 했다. 학습 없이 LLM + 풀이 예시 2개 | 71% (PaLM-540B) |
| Reflexion (NeurIPS 2023) | 실패를 글로 기억하게 했다. 반성문을 들고 같은 게임에 재도전 | 97% (130/134, 12회 시도) |

앞 논문이 남긴 문제가 다음 논문의 출발점입니다.

- ALFWorld는 실패하면 `Nothing happens.` 한 문장만 줍니다. ReAct는 생각(think)을 글로 써서 목표와 진행 상황을 붙잡습니다.
- ReAct는 한 판이 끝나면 아무것도 기억하지 못합니다. Reflexion은 반성문으로 경험을 다음 판에 넘깁니다.

세 논문에서 SKILL이 뜻하는 바도 다릅니다. ALFWorld에는 SKILL이라는 개념이 따로 없습니다. ReAct에서는 프롬프트 속 풀이 예시가 SKILL 역할을 하고, Reflexion에서는 자연어 반성 메모가 그 역할을 합니다.

## 2. ReAct — 생각과 행동을 번갈아

Yao et al., ICLR 2023 ([arXiv 2210.03629](https://arxiv.org/abs/2210.03629), 코드 [ysymyth/ReAct](https://github.com/ysymyth/ReAct))

**한 줄 요약.** 생각(Reasoning)과 행동(Acting)을 번갈아 하게 하면 둘이 서로를 도와, 하나만 할 때보다 훨씬 잘합니다.

### 2-1. 왜 둘을 섞나

- **생각만 하는 방식(Chain-of-Thought)**은 바깥 세상을 확인하지 않아서 그럴듯한 거짓(환각)을 만듭니다.
- **행동만 하는 방식(Act)**은 목표와 진행 상황을 잃고 같은 곳을 맴돕니다.
- **생각이 행동을 돕습니다.** 목표를 쪼개고("찾고 → 식히고 → 놓기"), 상식으로 탐색 순서를 정하고, 어디까지 했는지 추적합니다.
- **행동이 생각을 돕습니다.** "cabinet 6에 mug가 있다" 같은 실제 관측이 다음 생각의 근거가 되어 환각이 줄어듭니다.

### 2-2. 동작 방식

LLM은 매번 한 줄만 씁니다. 그 줄이 `think:`로 시작하면 코드가 게임에 보내지 않고 `OK.`만 돌려줍니다. 그 외의 줄은 행동으로 게임에 보냅니다.

```python
def alfworld_run(prompt, ob=''):
    init_prompt = prompt + ob + '\n>'      # 풀이 예시 2개 + 첫 관측
    prompt = ''
    for i in range(1, 50):                  # 최대 50스텝
        action = llm(init_prompt + prompt, stop=['\n'])
        observation, reward, done, info = env.step([action])
        if action.startswith('think:'):
            observation = 'OK.'             # 생각은 환경에 영향 없음
        prompt += f' {action}\n{observation}\n>'
        if done: return reward
    return 0
```

공식 코드에서 ALFWorld 부분은 이 루프와 풀이 예시 파일(`alfworld_3prompts.json`)이 사실상 전부입니다. 예시는 태스크 유형 6가지마다 3개씩 있고, 그중 2개를 고르는 조합 6가지로 돌린 결과 중 가장 좋은 것이 "best of 6"입니다.

### 2-3. 결과

| 방법 (PaLM-540B, 학습 없음) | Pick | Clean | Heat | Cool | Look | Pick2 | 전체 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| BUTLER (모방학습, best of 8) | 46 | 39 | 74 | 100 | 22 | 24 | 37 |
| Act — 예시에서 think만 삭제 (best of 6) | 88 | 42 | 74 | 67 | 72 | 41 | 45 |
| ReAct-IM — 매 스텝 생각 (best of 6) | 62 | 68 | 87 | 57 | 39 | 33 | 53 |
| ReAct (평균) | 65 | 39 | 83 | 76 | 55 | 24 | 57 |
| **ReAct (best of 6)** | **92** | **58** | **96** | **86** | **78** | **41** | **71** |

- 생각만 빼면 71%가 45%로 떨어집니다.
- 매 스텝 촘촘히 생각하게 하면(ReAct-IM) 53%입니다. 생각은 많이 하는 것보다 필요한 순간에 목적을 갖고 하는 게 중요합니다.
- 학습 없이 예시 2개만으로 모방학습 모델 BUTLER(37%)를 크게 넘었습니다.

### 2-4. 공통 틀로 보면

| 항목 | 내용 |
| --- | --- |
| 데이터 | 학습 데이터 없음. 사람이 쓴 유형별 풀이 예시(ALFWorld train에서) |
| 입력 → 출력 | 예시 2개 + 지금까지의 기록 → 다음 한 줄 (행동 또는 `think:`) |
| SKILL | 별도 라이브러리 없음. few-shot 예시가 유형별 풀이 템플릿 역할 (가중치 학습 없음) |
| 평가 | 성공률. PaLM-540B best of 6 71%, GPT-3(text-davinci-002) 78.4% |
| 언어적 문제 | 해결: 목표와 진행을 언어로 붙잡아 둠. 미해결: 한 판의 실패 경험이 다음 판으로 이어지지 않음 |

**읽으며 확인한 것.** 공식 프롬프트의 놓기 행동은 모두 `put X in/on Y` 문법입니다. 그런데 지난 글에서 본 것처럼 최신 alfworld(0.4.2)는 `move X to Y`만 받습니다. 원본 프롬프트를 그대로 쓰면 에이전트가 태스크를 거의 다 풀고 마지막 단계에서 실패할 것이라고 예상했습니다. 이 예상은 다음 글에서 확인합니다.

## 3. Reflexion — 실패를 글로 기억하게

Shinn et al., NeurIPS 2023 ([arXiv 2303.11366](https://arxiv.org/abs/2303.11366), 코드 [noahshinn/reflexion](https://github.com/noahshinn/reflexion))

**한 줄 요약.** 모델의 가중치를 바꾸는 대신, 실패를 반성문(자연어)으로 적어 기억에 넣고 같은 문제에 다시 도전합니다. 논문은 이것을 언어적 강화학습(verbal reinforcement learning)이라고 부릅니다.

### 3-1. 네 가지 부품

| 부품 | 하는 일 |
| --- | --- |
| Actor | ReAct 에이전트가 게임을 플레이. 그 판의 기록이 단기 기억 |
| Evaluator | 성공/실패 판정. ALFWorld에서는 휴리스틱으로, 같은 행동·같은 결과가 3회 넘게 반복되거나 행동이 30개를 넘으면 실패로 봄 |
| Self-Reflection | LLM이 실패한 기록을 읽고 "무엇이 틀렸고 다음엔 어떻게 할지" 반성문 작성 |
| Memory | 반성문을 쌓아 다음 시도 프롬프트 앞에 붙임 (최근 3개까지) |

한 게임을 기준으로 흐름을 정리하면 이렇습니다.

1. **1차 시도**: 예시를 보고 게임을 플레이했다가 실패합니다.
2. **반성**: 1차 기록을 읽고 "왜 실패했고 다음엔 어떻게 할지" 반성문을 씁니다.
3. **2차 시도**: 예시와 반성문을 들고 같은 게임을 처음부터 다시 합니다.
4. **반복**: 또 실패하면 반성문을 하나 더 쌓아 다시 도전합니다.

### 3-2. 결과

- ALFWorld에서 ReAct + Reflexion이 134게임 중 **130게임(97%)**을 풀었습니다. 12번 연속 시도한 결과이고, ReAct만 쓴 것보다 절대 +22%p 높습니다.
- 질의응답(HotpotQA)에서 +20%p, 코드 생성(HumanEval)에서 pass@1 91%를 냈습니다. 같은 시기 GPT-4는 80%였습니다.

### 3-3. 공통 틀로 보면

| 항목 | 내용 |
| --- | --- |
| 데이터 | 학습 없음. ReAct 예시 + 반성문 예시(few-shot) |
| 입력 → 출력 | 실패한 기록 → 반성문(자연어) → 다음 시도 프롬프트에 `Your memory for the task below:`로 추가 |
| SKILL | 자연어 반성 메모. 그 게임 하나에 대한 경험 기록이고, 다른 게임에 쓰는 기술 라이브러리는 아님 |
| 평가 | 시도 횟수에 따른 누적 성공률 |
| 언어적 문제 | 반성문이 실패 원인을 맞게 짚는다는 가정 위에 서 있음 |

**읽으며 궁금했던 것.** 마지막 줄이 핵심이었습니다. ALFWorld는 실패 이유를 말해 주지 않습니다(`Nothing happens.`). 그런데도 반성문이 진짜 원인을 짚을 수 있을까요? 다음 글에서 직접 돌려 보며 반성문을 하나하나 읽었습니다.

## 4. 정리

- ReAct: 언어(생각)가 행동 선택을 바꾼다는 기초 증거입니다. think를 빼면 71%가 45%로 떨어집니다.
- Reflexion: 언어(반성문)로 경험을 다음 시도에 넘깁니다. 12회 시도로 97%를 냈습니다.
- 두 논문 모두 언어가 정확하다는 가정 위에 서 있습니다. 예시 문법이 환경과 맞아야 하고, 반성문이 원인을 맞혀야 합니다. 다음 두 글은 이 가정이 깨질 때 어떤 일이 생기는지에 대한 기록입니다.
