이전 시리즈: 마인크래프트 에이전트 논문 읽기

이 글에 대해 ALFWorld 실험에서는 지시문의 동사 하나가 성공률을 45%에서 80%로 바꿨습니다. 글이 아니라 화면을 보고 마우스를 움직이는 모델에서도 같은 일이 일어나는지 작은 규모로 확인했습니다. 지시문마다 5판뿐인 예비 실험이라, 결론이 아니라 신호로 읽어야 합니다.

1. 한눈에

항목 내용
질문 같은 일을 다른 문장으로 시키면 행동과 성과가 달라지는가
과제 나무 모으기
조건 지시문 8개 × seed 0–4 = 40판 (기준 지시문 5판은 재현 실험 결과 사용)
설정 재현 실험과 같음. 3000스텝, λ = 6, forest 시작
지표 한 판 동안 인벤토리에 보인 나무의 최대 개수
결과 “cut down a tree” 6.0개, “get wood” 0.4개, “don’t chop trees” 4.4개

2. 실행 전에 적어 둔 가설

결과를 보고 나서 이야기를 맞추지 않으려고, 돌리기 전에 예상을 먼저 적었습니다.

가설 예상 근거
H1 동의어 같은 뜻이라도 표현에 따라 차이가 크다 STEVE-1 논문의 지시문 민감도, CrafText의 결과
H2 부정문 “하지 마”가 무시되어 나무를 캔다 문장 전체를 벡터 하나로 압축하는 인코더 구조
H3 자세한 지시 길게 나열한 지시문이 짧은 지시문보다 낫다 논문에서 나무 약 1.6배

3. 지시문 여덟 개

유형 지시문
기준 “chop a tree”
동의어 “cut down a tree”, “collect logs”, “get wood”
명사만 “tree”
자세한 지시 “chop down the tree, gather wood, pick up wood, chop it down, break tree” (논문 Table 3)
부정문 “don’t chop trees”
대조군 “go swimming”

모든 지시문이 같은 seed 0–4의 월드에서 시작합니다. 지형 차이를 빼고 문장의 영향만 보기 위해서입니다.

대조군은 “아무 말이나 해도 어차피 나무를 캐는 것 아닌가”를 확인하려고 넣었습니다.

4. 결과

지시문별 나무 수집량. 5판 평균과 95% 신뢰구간입니다.
지시문 seed 0 1 2 3 4 평균
“cut down a tree” 4 8 6 9 3 6.0
자세한 지시 – – – – – 5.2
“don’t chop trees” 5 3 4 4 6 4.4
“chop a tree” 3 0 6 2 8 3.8
“collect logs” 2 0 3 5 0 2.0
“tree” 3 0 0 3 0 1.2
“get wood” 1 0 1 0 0 0.4
“go swimming” 0 0 0 0 0 0.0

자세한 지시문은 문장 안의 쉼표 때문에 결과 파일에서 판별 값을 뽑지 못해 평균만 적었습니다. 신뢰구간은 ± 6.3으로 매우 넓습니다.

5. 가설과 맞춰 보기

가설 결과 판정
H1 동의어 “cut down a tree” 6.0, “collect logs” 2.0, “get wood” 0.4 예비 실험 수준에서 지지
H2 부정문 “don’t chop trees” 4.4, 5판 모두 3개 이상 예비 실험 수준에서 지지
H3 자세한 지시 5.2 ± 6.3. 기준의 1.4배 방향은 논문과 같지만 판단 보류

눈에 띄는 것 세 가지입니다.

  • “get wood”는 대조군에 가깝습니다. 사람에게는 “chop a tree”와 같은 말인데, 5판 중 3판에서 하나도 모으지 못했습니다.
  • “don’t chop trees”는 나무를 캤습니다. 기준 지시문보다 평균이 높고, 5판 모두 3개 이상이라 오히려 가장 고르게 캤습니다.
  • “go swimming”은 5판 모두 0개입니다. 그러니 나무를 캐는 것은 기본 습관이 아니라 지시문에서 나온 행동입니다. 부정문이 나무를 캔 것도 “아무 말에나 나무를 캔다”로는 설명되지 않습니다.

6. 왜 이럴까 (추측)

아직 확인하지 않은 설명입니다.

  • 눈에 보이는 동작을 묘사한 문장에 강한 것 같습니다. “cut down a tree”는 화면에서 벌어지는 장면을 그대로 말합니다. “get wood”나 “collect logs”는 결과물(아이템)을 말합니다. 지시문을 벡터로 바꾸는 MineCLIP은 게임 영상과 그 설명으로 학습됐으니, 장면을 묘사하는 문장에 더 잘 반응할 수 있습니다.
  • 부정어는 벡터로 압축되면서 거의 사라지는 것 같습니다. “don’t chop trees”와 “chop trees”는 단어가 거의 같습니다. 문장 전체를 벡터 하나로 만들면 두 벡터가 가깝게 나올 가능성이 큽니다.

두 번째 추측은 실험 없이도 확인할 수 있습니다. 두 문장의 벡터를 뽑아 거리를 재면 됩니다.

7. 비슷한 보고

같은 시기에 로봇 분야에서도 비슷한 현상이 보고됐습니다. 둘 다 아직 심사 전 논문(프리프린트)입니다.

연구 대상 내용
RoboFollow (2026.09) 로봇 조작 모델 9종 학습 때 본 지시문에서는 높은 점수, 익숙한 개념을 새로 조합한 지시문에서는 크게 하락
NegaBench (2026.10) 로봇 조작 모델 “칼 빼고 도구를 줘” 같은 부정 지시의 성공률이 매우 낮음

화면을 보고 움직이는 모델이 지시문을 따르는 것처럼 보여도, 문장의 뜻을 처리하는지는 따로 확인해야 한다는 점에서 같은 이야기입니다.

8. 한계

  • 지시문마다 5판입니다. 신뢰구간이 넓어서 순위는 바뀔 수 있습니다.
  • 과제가 나무 하나이고 시작 지형이 forest로 고정돼 있습니다.
  • 부정문이 하나뿐입니다. “avoid trees” 같은 다른 표현은 시험하지 않았습니다.
  • 영상은 seed 0만 저장했고, 실패한 판에서 에이전트가 실제로 무엇을 했는지는 아직 분류하지 않았습니다.

9. 정리

  • 같은 뜻의 지시문 사이에서 평균 수집량이 0.4개에서 6.0개까지 갈렸습니다.
  • 부정문은 반영되지 않았고, 대조군은 0개였습니다.
  • ALFWorld에서 본 “지시문 표현이 성과를 좌우한다”는 현상이, 글이 아니라 화면을 입력으로 받는 모델에서도 예비 실험 수준에서 다시 나타났습니다.
  • 다음에는 판 수를 늘리고, 흙 과제와 다른 부정 표현을 더하고, 문장 벡터의 거리를 재서 원인을 확인하려 합니다.
